# Sample models

Models are not committed. Fetch the test models with `sh samples/download.sh` (four GLBs from the
[Khronos glTF Sample Assets](https://github.com/KhronosGroup/glTF-Sample-Assets)), or build synthetic ones with
`python tools/make_samples.py` (into `samples/synthetic/`). Drop your own `.glb` files here too.

images in `examples/` use Fox, Avocado, the synthetic sphere, and a stone giant made with Tripo (that model is not
included).
